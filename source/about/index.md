我是刘志宁，一个不甘平凡喜欢折腾的博主。

我折腾博客的历史最早可以追溯到大学时代，这些年，从 .NET 到 WordPress，我试过各种博客程序，域名也从 liuzn.cn 换到了现在的 liuzhining.com。

最终，我选择了 Hexo + GitHub 的极致组合，除了宝贵的时间成本，没有服务器的额外开销。

**我写博客不是为了流量，也不是为了博取他人关注。**

在 AI 时代，我不想再写那些能通过 AI 获取标准答案的文章，而是想记录一些个人经历感悟。

这里是我的知识沉淀池，也是我重新出发的起点。
